# 🎧 一起听 · 产品介绍

> 一句话：打开网页、输入房间码，和天南地北的朋友同步听同一首歌。

## 这是什么

「一起听」是一个**无需安装、无需注册**的网页版同步听歌工具。创建房间、把链接或房间码发给朋友，大家就能在同一时刻听到同一首歌的**同一个进度**——播放、暂停、切歌、拖进度条全部实时同步，还能边听边聊。

手机、电脑、平板，浏览器打开即用；支持 FLAC 无损格式，iPhone 微信里也能流畅同步播放。

## 主要功能

### 🚪 秒开房间，即开即用

- 浏览器打开即用，**无需下载 App、无需注册登录**
- 6 位房间码，输满自动高亮；分享链接一键进房
- 房间号使用得意黑字体展示，一眼可读

### 🎵 三路曲源，想听什么都有

- **上传音频**：MP3 / FLAC / WAV / M4A / AAC / OGG / OPUS 等 9 种常见格式，单文件最大 200MB，原生支持无损
- **本地曲库**：服务器曲库即搜即加，支持子文件夹
- **在线音乐**：网易云 + 咪咕双平台聚合搜索、分页浏览；歌曲无版权或会员受限时**自动切换另一平台**，同一首歌总有一个源能播

### ⏱️ 全房间同步播放

- 播放 / 暂停 / 切歌 / 拖进度实时同步，顺序 / 随机 / 单曲循环三种模式
- **智能纠偏**：各设备进度偏差自动校准，且不会反复跳转造成卡顿
- 加入第一首歌自动开播；删掉正在播的歌自动切下一首

### 💬 边听边聊

- 房内实时聊天，新成员进房可看到最近 100 条消息
- 长按自己的消息即可撤回，说错话不留痕

### 📱 移动端深度优化（iPhone / 微信实测打磨）

- FLAC 无损时长精准解析，iOS 流式播放不再"卡在 0 秒"
- 锁屏 / 切后台自动重连，成员列表不闪"离开/进来"
- 进度条本地即时响应，拖拽不卡顿

## 核心优势

1. **零门槛**：无 App、无注册、无学习成本，发个链接就能一起听
2. **无损音质**：原生支持 FLAC 高保真，不只是"能听个响"
3. **曲库自由**：自己的歌传上去、在线音乐搜着加，不受平台曲库限制
4. **双源兜底**：网易云 / 咪咕自动换源，无版权、会员受限的歌大概率仍有替代源可播
5. **省流量**：可选腾讯云 COS 内容上云，播放走对象存储 / CDN，个人设备只承担一次上传带宽
6. **轻量部署**：一台旧手机（Termux）或最低配云服务器即可 7×24 小时在线，个人使用成本几乎为零
7. **干净纯粹**：无广告、无会员套路、无数据收集，纯朋友间的听歌角落

## 适用场景

- **异地朋友 / 异地恋**：一起听同一首歌，距离不再是隔阂
- **游戏开黑**：边语音边放 BGM，气氛拉满
- **学习 / 工作陪伴**：同步播放白噪音或歌单，远程"在一起"
- **同好小圈子**：无损专辑、冷门歌单一起赏析

## 快速开始

打开 http://listen.example.com:3000 → 创建房间 → 把房间码发给朋友 → 一起听

## 定位说明

「一起听」定位为**朋友间小圈子使用**：无账号体系、无内容审核，在线音乐依赖非官方接口。适合分享给认识的朋友（10～50 人规模），不建议作为面向公众的大规模宣传产品。
