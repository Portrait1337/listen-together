# 🎧 一起听（网页版原型）

一个"群友一起听"的最小原型：创建房间 → 上传音频、从本地曲库或在线音乐搜索添加 → 全房间同步播放，还能房内聊天。

## 运行

1. 安装 Node.js 18 或更高版本（https://nodejs.org）
2. 在项目目录执行：

```bash
npm install
npm start
```

3. 浏览器打开 http://localhost:3000

## 和朋友一起试

- **同一 Wi-Fi**：查一下电脑的局域网 IP（macOS：系统设置 → 网络），让朋友用手机浏览器打开 `http://<电脑IP>:3000`。
- **不在同一网络**：用隧道把本地服务暴露到公网，例如：

```bash
brew install cloudflared
cloudflared tunnel --url http://localhost:3000
```

会得到一个 https 临时地址，发给群友即可。

## 使用流程

1. 创建房间 → 把房间码或链接发给群友
2. 群友打开链接，填昵称加入
3. 任一人上传音频（支持常见音频格式，单文件 200MB 以内）
4. 也可以在播放列表上方的搜索框搜本地曲库或在线音乐，点"添加"把歌加进列表
5. 点播放，大家同步听到同一进度；可以暂停、切歌、拖进度、聊天

## 本地曲库

- 把提前下载好的音频文件放进项目里的 `library` 文件夹（支持子文件夹，常见音频格式均可）
- 房间内的任何人都能搜索曲库并添加歌曲到当前播放列表
- `library` 文件夹已在 `.gitignore` 中，不会进入版本库；服务器启动时如不存在会自动创建
- 曲库文件由你自行准备，本应用不负责从网络下载音乐

## 在线曲库

- 搜索框切到"在线音乐"，可搜索咪咕与网易云的免费歌曲并添加（咪咕结果优先展示）
- 添加时歌曲会下载到 `library/online/`，之后按本地文件播放，全房间同步
- 网易云无版权或会员受限的歌会自动尝试咪咕同歌换源；会员（VIP）歌不可添加
- 在线接口为非官方接口，可能随时失效，仅供个人/小圈子测试，请勿商用

## 原型阶段已知限制

- 数据存在内存里，服务器重启后房间、歌单和上传的音频都会消失
- 上传的音频存在本地磁盘，用户多了需要换成对象存储 + CDN
- 任何人都能控制播放，还没有房主权限
- 版权机制，只适合小圈子测试

## 下一步建议

- 对象存储 + CDN，音频独立存放
- 部署到服务器并启用 HTTPS
- 上传已做扩展名白名单 + 文件头 magic bytes 校验，后续可升级为深度解析（如 ffprobe）
