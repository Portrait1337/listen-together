# 🎧 一起听

一个"群友一起听"的网页版：创建房间 → 上传音频、从本地曲库或在线音乐添加歌曲 → 全房间同步播放，还能房内聊天。

## 功能

- **房间与同步播放**：播放、暂停、切歌、拖进度全房间同步；随机模式自动切歌
- **聊天**：房内实时聊天，新成员可看到最近 100 条消息
- **上传音频**：常见音频格式、单文件 200MB 以内，带扩展名白名单、文件头校验与限流
- **本地曲库**：搜索 `library` 文件夹里的歌并添加
- **在线音乐**：网易云 + 咪咕双源搜索，自动换源、分页加载、限速缓存；播放列表加入第一首歌后自动开播
- **网易云会员歌（可选）**：配置 Cookie 后会员歌可在线播放，不落盘

## 运行

1. 安装 Node.js 18 或更高版本（https://nodejs.org）
2. 在项目目录执行：

```bash
npm install
npm start
```

3. 浏览器打开 http://localhost:3000（可用环境变量 `PORT` 改端口）

## 和朋友一起试

- **同一 Wi-Fi**：让朋友用手机浏览器打开 `http://<电脑局域网IP>:3000`
- **临时公网**：用隧道暴露本地服务，例如 `cloudflared tunnel --url http://localhost:3000`；也可以使用项目自带的 cpolar 开机自启脚本（见 `scripts/README.md`）
- **长期在线**：
  - 云服务器一键部署：`./deploy/deploy.sh 用户名@服务器IP`（systemd 自启、崩溃自动重启，详见 `deploy/README.md`）
  - 旧手机自托管：`deploy/phone/` 部署包，配合光猫端口映射与 DDNS 配置（见 `deploy/router-公网IP配置.md`）

## 使用流程

1. 创建房间 → 把房间码或链接发给群友
2. 群友打开链接，填昵称加入
3. 添加歌曲：上传音频，或搜索本地曲库 / 在线音乐后点"添加"
4. 点播放，大家同步听到同一进度；可以暂停、切歌、拖进度、聊天

## 本地曲库

- 把音频文件放进项目里的 `library` 文件夹（支持子文件夹，常见音频格式均可）
- 房间内的任何人都能搜索曲库并添加歌曲到当前播放列表
- `library` 已在 `.gitignore` 中，不会进入版本库；服务器启动时如不存在会自动创建
- 曲库文件由你自行准备，本应用不负责从网络下载音乐

## 在线音乐

- 搜索框切到"在线音乐"，可切换平台（网易云 / 咪咕）分开检索，咪咕结果默认优先展示
- 免费歌曲添加后会下载到独立的 `online-cache/` 目录（不在曲库里，搜索不到），之后按本地文件播放，全房间同步
- 网易云无版权或会员受限的歌会自动尝试咪咕同歌换源；会员歌未配置 Cookie 时不可添加
- 在线接口为非官方接口，可能随时失效，仅供个人/小圈子测试，请勿商用

## 网易云会员歌曲（可选）

- 把网易云登录 Cookie 写入项目根目录的 `netease-cookie.txt`（或设环境变量 `NETEASE_COOKIE`），会员歌即可在线播放
- 获取方式：浏览器登录 music.163.com（建议专用小号），F12 → Network → 复制任意请求的 Cookie 头
- 会员歌只在线播放、不下载保存；播放地址由服务器现取，Cookie 不会下发到浏览器
- Cookie 通常 7 天～2 周过期，改文件即生效（30 秒内自动重读）；失效后会员歌自动恢复不可添加，免费歌不受影响
- 风险提示：网易云会风控第三方登录，账号可能被临时冻结，请勿使用主账号

## 开发

- 运行测试：`node --test`（node:test，覆盖房间生命周期与成员、聊天历史、播放列表、上传校验与限流、WebSocket 防护、在线搜索、VIP、同步策略）
- 无构建步骤：后端 CommonJS，前端原生 JS，直接改 `public/` 即可
- 目录速览：`server.js`（服务与 WebSocket）、`online.js`（在线音乐）、`public/`（前端）、`test/`（测试）、`deploy/`（部署）、`scripts/`（macOS 隧道）、`docs/`（设计文档）
- 开发约定见 [AGENTS.md](AGENTS.md)

## 原型阶段已知限制

- 数据存在内存里，服务器重启后房间、歌单、聊天历史都会消失
- 上传的音频存在本地磁盘，用户多了需要换成对象存储 + CDN
- 任何人都能控制播放，还没有房主权限
- 没有登录、内容审核机制，只适合小圈子测试
- 在线音乐依赖非官方接口，可能随时失效

## 下一步建议

- 房主权限（只有房主能控制播放）
- 数据持久化（数据库保存房间、歌单、播放历史）
- 对象存储 + CDN，音频独立存放
- 绑定域名并启用 HTTPS
- 上传深度解析（如 ffprobe）与内容安全检测
