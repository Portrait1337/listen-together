# 公网访问与端口映射配置（通用教程）

本文以运行 Termux 的手机为服务端，应用监听 3000 端口为例。`listen.example.com` 是示例域名，使用时换成自己的域名；网关地址、手机地址和端口均以实际网络配置为准。

## 1. 确认公网访问条件

1. 在联网网关的管理界面查看 WAN 地址，并与外部查询到的出口公网地址核对。
2. 确认入站连接可以到达自己的网关；若处于运营商 NAT 后，需要先联系网络服务提供方确认公网接入条件，或使用隧道方案。
3. 在手机上确认应用已启动：用本机浏览器打开 `http://localhost:3000`。

## 2. 选择端口映射位置

- 单层 NAT：在持有公网地址的网关上，将外部 TCP 3000 端口转发到运行服务的手机 TCP 3000 端口。
- 多层 NAT：需要逐层配置转发；也可以调整连接方式，让手机接入持有公网地址的网关所管理的局域网，再只配置这一层映射。
- 若设备没有端口映射功能，查看设备官方说明或联系管理员；也可改用云服务器或隧道部署。

不同网关的菜单名称可能是“端口转发”“端口映射”“NAT”或“虚拟服务器”，以设备界面为准。

## 3. 配置手机地址与转发规则

1. 在手机 WiFi 详情中查看当前局域网地址，在网关后台为手机设置 DHCP 地址保留，避免手机地址变化后转发失效。
2. 登录实际网关管理地址，添加一条规则：
   - 协议：TCP
   - 外部端口：3000
   - 内部设备：运行「一起听」的手机
   - 内部地址：手机当前局域网地址
   - 内部端口：3000
3. 如有防火墙或访问控制规则，确认允许该入站端口。
4. 配置手机端 DDNS，使域名跟随动态公网地址更新，见 [手机 DDNS 配置说明](phone/DDNS配置说明.txt)。

## 4. 从外部网络验证

保留服务手机的网络连接，使用另一台设备关闭 WiFi、切换移动数据，或从其他外部网络访问 `http://listen.example.com:3000`。

1. 能打开页面后，创建房间并上传一段自备测试音频。
2. 用另一浏览器或设备加入同一房间，确认播放、暂停和聊天可以同步。
3. 无法访问时，依次检查：
   - 服务手机能否打开 `http://localhost:3000`；
   - 端口映射目标是否仍是服务手机的当前地址；
   - 多层 NAT 是否每一层都有对应规则；
   - 网关与主机防火墙是否允许该端口；
   - 域名解析结果是否等于当前公网地址；
   - 网络服务提供方是否允许该端口的入站访问。

## 动态地址与替代方案

- 公网地址变化后，DDNS 更新与 DNS 缓存过期都需要时间；以实际更新日志和解析结果核对。
- 若外部端口受限，可以选择允许的端口并同步调整映射与访问链接。
- 无法配置公网入站时，可采用项目提供的隧道部署方式；地址稳定性、带宽与费用以所选服务的实际方案为准。
