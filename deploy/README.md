# 部署到云服务器（电脑关机也能用）

## 原理

现在服务跑在你的 Mac 上，关机就没了。把它搬到一台 24 小时在线的云服务器上，服务器有公网 IP，
朋友直接访问 `http://服务器IP:3000`，不再需要 cpolar 隧道。

## 第一步：买服务器（二选一）

**推荐：香港轻量服务器（约 30 元/月，省心）**

- 腾讯云轻量应用服务器（香港）或阿里云轻量应用服务器（香港），系统选 Ubuntu 22.04/24.04
- 1 核 1G 起步就够，新用户常有优惠活动（可能 99 元/年左右）
- 香港节点国内直连、不用备案

**免费：Oracle Cloud Always Free**

- 注册甲骨文云，区域选首尔/大阪/东京，创建 Ampere ARM 实例（免费额度 4 核 24G）
- 完全免费，但要信用卡验证，偶尔会碰到"无可用容量"；国内访问速度看线路

大陆节点（阿里云/腾讯云大陆）需要 ICP 备案才能对外提供网站服务，第一次不建议选。

## 第二步：准备服务器

1. 拿到公网 IP 和 SSH 登录方式（控制台会生成密钥，或自己设置密码）
2. 装 Node.js 18+：

   ```bash
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt-get install -y nodejs
   node -v   # 确认显示 v20.x
   ```

3. 在云控制台的安全组/防火墙里放行 TCP 3000 端口

## 第三步：一键部署

在 Mac 上、项目目录里执行：

```bash
./deploy/deploy.sh ubuntu@你的服务器IP
```

脚本会自动：同步代码 → 安装依赖 → 注册 systemd 服务（开机自启、崩溃自动重启）→ 启动并自检。

部署完打开 `http://你的服务器IP:3000` 就能用了。服务器重启后服务也会自动恢复。

## 常见问题

- 忘记 SSH 登录方式：云控制台可以直接重置
- 想绑域名和 HTTPS：买一个域名（.com 即可），再装 nginx + certbot，需要的话我可以帮你配置
- 服务器重启后房间会丢（数据在内存里），但上传的音频文件会保留在服务器磁盘上
- 以后本地改完代码要上线：重新执行一次 `./deploy/deploy.sh` 即可，脚本会自动保留服务器上的上传文件
- 云端部署好之后，Mac 上的 cpolar 自启隧道就不需要了，可以停掉（告诉我一声，我帮你卸载）
