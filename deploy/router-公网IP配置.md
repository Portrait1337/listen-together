# 公网 IP 生效后的配置（光猫直连方案）

## 当前网络现状（2026-08-10 实测）

- 公网 IP 已生效：出口 183.191.231.66，路由第三跳已从 10.220.0.1（大内网）变为 183.191.228.1（公网）
- 光猫（192.168.1.1）仍在做路由，所以是双层 NAT：
  光猫(公网) → OpenWrt 路由器(192.168.2.254) → 手机
- ⚠️ 重要发现（2026-08-11）：路由器是联通定制"全屋通 MSG1500"，
  精简固件没有端口映射和 DDNS 功能，无法在路由器上做转发。
  因此改用"光猫直接映射到手机"的方案，手机需要连光猫的 WiFi（光猫局域网）。

## 新方案：光猫直连手机

1. 手机改连**光猫的 WiFi**（光猫一般自带 WiFi，机身或贴纸上有名称/密码；
   没有的话问师傅开启，或让师傅直接配置光猫端口映射）
2. 手机连上后，看手机 WiFi 详情里的 IP，应该变成 192.168.1.x
3. 光猫后台（192.168.1.1）做端口映射：
   - 外网端口 3000 → 手机 IP（192.168.1.x）的 3000 端口
   - 端口映射一般在"应用 → 端口映射/NAT"菜单；普通账号看不到时，
     需要光猫超级管理员密码（CUAdmin），找宽带师傅要
4. DDNS 不用路由器配：手机上的 ddnspod-update.sh 会自动更新域名解析（见 DDNS配置说明.txt）

## 验证（手机流量测试）

1. 手机关闭 WiFi，用流量打开  http://你的域名:3000
2. 能打开「一起听」页面 → 全部配置完成 ✓
3. 打不开 → 按顺序检查：
   - 光猫端口映射是否生效（外网 3000 → 手机 192.168.1.x:3000）
   - 手机是否连在光猫 WiFi 上（IP 应为 192.168.1.x）
   - 手机服务是否在跑（手机浏览器 localhost:3000）
   - DDNS 解析出的 IP 是否等于当前公网 IP

## 备注

- 家庭宽带的 80/443 端口通常被运营商封禁，所以坚持用 3000 端口，不要改 80
- 公网 IP 是动态的（会变），DDNS 会自动跟着更新，不用管
- 换 IP 后旧地址会失效几分钟，属正常现象
- 如果光猫端口映射实在搞不定（拿不到超级管理员），退回 cpolar 隧道方案：
  手机 Termux 里装 cpolar，同样能用，代价是带宽 1Mbps 和地址会变
