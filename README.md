# 🎧 一起听（网页版原型）

一个"群友一起听"的最小原型：创建房间 → 上传音频 → 全房间同步播放，还能房内聊天。

## 运行

1. 安装 Node.js 18 或更高版本（https://nodejs.org）
2. 在项目目录执行：

```bash
npm install
npm start
```

3. 浏览器打开 http://localhost:3000

## 和朋友一起试

- **同一 Wi-Fi**：查一下电脑的局域网 IP（macOS：系统设置 → 网络），让朋友用手机浏览器打开 `http://<电脑IP>:3000`。
- **不在同一网络**：用隧道把本地服务暴露到公网，例如：

```bash
brew install cloudflared
cloudflared tunnel --url http://localhost:3000
```

会得到一个 https 临时地址，发给群友即可。

## 使用流程

1. 创建房间 → 把房间码或链接发给群友
2. 群友打开链接，填昵称加入
3. 任一人上传音频（支持常见音频格式，单文件 200MB 以内）
4. 点播放，大家同步听到同一进度；可以暂停、切歌、拖进度、聊天

## 原型阶段已知限制

- 数据存在内存里，服务器重启后房间、歌单和上传的音频都会消失
- 上传的音频存在本地磁盘，用户多了需要换成对象存储 + CDN
- 任何人都能控制播放，还没有房主权限
- 没有登录、内容审核、版权机制，只适合小圈子测试

## 下一步建议

- 房主权限（只有房主能控制播放）
- 对象存储 + CDN，音频独立存放
- 部署到服务器并启用 HTTPS
- 上传先做内容安全检测，通过后才可播
- 数据持久化（数据库保存房间、歌单、播放历史）
